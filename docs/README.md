The `historical/` directory contains previous documentation files that may still be useful for reference but are no longer actively maintained:

## 🗄️ Archive

The `archive/` directory contains development files and configurations that were moved from the root directory during cleanup:
- Previous shared utilities
- Old development scripts
- IDE configurations
- Environment templates

## 📝 Documentation Guidelines

When working on the project:
1. Keep current, actively-used documentation in `current/`
2. Move outdated but potentially useful docs to `historical/`
3. Archive development artifacts and configs to `archive/`
4. Update this README when adding new documentation
